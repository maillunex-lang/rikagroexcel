# Прайс-мост Portable

Локальная программа для сопоставления прайс-листов Excel. Обработка данных происходит на компьютере, без отправки файлов на сервер.

## Сборка Windows

1. Поместите файлы веб-приложения в `dist/`: `index.html`, `app.js`, `engine.js`, `style.css`, `vendor/xlsx.full.min.js`.
2. Откройте **Actions**, выберите **Build Windows Portable**, нажмите **Run workflow**.
3. Скачайте EXE из артефакта сборки. Для публикации в Releases создайте тег `vX.Y.Z`.

Программа без пароля. EXE содержит Chromium и не требует WebView2. При работе с Excel интернет не нужен.

**Важно:** сборка завершается ошибкой, если исходники веб-приложения не добавлены в `dist/`.
