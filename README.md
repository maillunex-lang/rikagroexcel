# Прайс-мост Portable

Локальное приложение для добавления выбранных столбцов из Excel-файлов в исходную таблицу. Сопоставление товаров по артикулу, названию или сначала артикулу, затем названию. Несовпавшие позиции остаются пустыми. Исходные строки не изменяются. Исходный файл на диске не изменяется, результат сохраняется отдельно.

## Использование

1. Загрузите исходный Excel и выберите лист и строку заголовков.
2. Добавьте один или несколько файлов, отметьте нужные столбцы.
3. Нажмите «Скачать Excel». Заголовки новых столбцов формируются из имён файлов. Если из одного файла выбрано несколько столбцов, к имени добавляется буква.

Если в файле поставщика больше строк, результат может содержать дополнительные строки. Формулы и сложное форматирование могут отличаться после пересохранения библиотекой XLSX.

## Сборка

Workflow **Build Windows Portable** собирает Windows x64 EXE при создании тега `vX.Y.Z` или ручном запуске. Приложение не требует установки или пароля, не отправляет Excel в интернет.
